---

## 1. 摘要

该工具在 Windows 上执行命令时，会通过沙箱适配器对**工作区根目录**做隔离处理。本次事故中工作区被指定为用户桌面，沙箱把该目录的**完整性级别降为 Low，并附加禁止向上写（No-Write-Up）**。

标签带 `(OI)(CI)`，会**递归继承**给目录下所有文件与子目录。结果整张桌面在系统眼中变成「不受信任的低完整性区域」，用户以中完整性身份（资源管理器、办公软件）进行的一切写入型操作被拦截。

用户可见表现三类：打开/双击被安全警告拦截、文件无法移入桌面、快捷方式图标变白板。全过程无文件损坏、无凭据泄露。

---

## 2. 影响面

| 受影响操作 | 表现 | 严重度 |
|---|---|---|
| 双击桌面文件 / 快捷方式 | 弹「打开文件 - 安全警告」「Windows 安全中心：打开这些文件可能会对你的计算机有害」 | 高（每次操作被打断） |
| 从其他目录把文件移入桌面 | 「访问被拒绝」类报错 | 高（日常整理受阻） |
| 桌面快捷方式图标 | 大量变为空白页 + 箭头 | 中（易误判为文件损坏） |
| 第三方程序写入桌面 | 同上被拒 | 中 |
| 数据完整性 | 无文件被删除或损坏 | 无 |
| 保密性 | 无凭据、无内容外泄 | 无 |

**未受影响**：进入文件夹本身（读取不需要写权限）、其他磁盘、网络访问。

---

## 3. 根因

> 沙箱把工作区根目录的完整性级别降为 `Low` 并附加 `(NW)`，标签递归继承，把用户桌面整体降级。

沙箱适配器对工作区做了三件事：

1. 为合成 SID（`S-1-4-*`）授予写权限 —— 正常机制，无害；
2. 在工作区根目录添加 `Everyone: 拒绝 删除子文件夹及文件` —— 影响有限（用户本人另有 FullControl）；
3. **将工作区根目录的强制标签设为 `Low` + `(NW)`** —— **本次事故的直接原因**。

第 3 项带 `(OI)(CI)`，因此从工作区根目录向下传播到每个已存在和之后新建的对象。

## 4. 证据链

| # | 检查项 | 命令 / 方法 | 结果 | 结论 |
|---|---|---|---|---|

| E2 | 子项继承 | `icacls` 逐个文件 | 均带 `Low Mandatory Level:(I)(NW)` | 标签已递归继承 |

| E4 | 下载标记（MOTW） | 遍历桌面 7,026 个文件查 `Zone.Identifier` | 131 个有标记，全部为真实下载件；工具生成的文件 0 个 | 排除「文件带下载标记」 |
| E5 | 扩展属性 | `fsutil file queryea` | 无 EA | 排除 EA 存储区域信息 |

## 5. 风险评级

- **可用性：高影响** —— 桌面上的复制、移动、删除、程序写入全部受阻。
- **完整性：中影响** —— 目录安全属性被第三方工具修改（可恢复，未损坏数据）。
- **保密性：无影响**。
- **可复发性：确定会复发** —— 只要工作区仍指向桌面，工具每次启动/执行都会重新施加降级。

综合等级：**中**（非破坏性，但造成持续的功能性阻断与误导性安全提示）。

## 6. 处置措施

### 6.1 已执行（有效）

| 措施 | 说明 |
|---|---|
| 恢复完整性级别 | 管理员 PowerShell：`icacls "$env:USERPROFILE\Desktop" /setintegritylevel "(OI)(CI)M" /T /C` |
| 重启资源管理器 / 重启系统 | 让图标缓存按新完整性重建 |

### 6.2 已执行（次要，无害）

| 措施 | 说明 |
|---|---|
| 安全软件信任区添加该工具主程序 | 抑制 HIPS 对「隐藏窗口 PowerShell」的反复提示（与根因无关） |
| 解除 131 个真实下载件的 Internet 标记 | 与本次故障无关，属顺手清理 |

### 6.3 已执行并**已还原**（无效尝试的副作用清理）

| 改动 | 状态 |
|---|---|
| `HKCU\...\Internet Settings\Zones\0-3` 的 `1806` 改为 0 | 已删除，恢复默认 |
| `HKCU\...\ZoneMap\ProtocolDefaults\file` 改为 0 | 已改回 3（Windows 默认） |
| `HKLM\...\Policies\Attachments\ScanWithAntiVirus`（原值 3） | 已删除（用户以管理员执行） |

### 6.4 待执行（防复发）

1. **新建专用工作区目录**，例如 `D:\Agent-Work`，不再使用桌面；
2. 在工具侧栏「工作区 → ＋ → 添加工作区」选择该目录；
3. 旧会话归档即可（该工具不支持给已有会话更换工作区）。

---

## 9. 一句话教训

> **看见「安全提示」先别信提示的措辞。** 「Internet 安全设置」「可能有害」这些词把人引向「文件来源标记」，而真正的原因是一个从没出现在弹窗里的词：**完整性级别**。
>
> 下次遇到「某类操作全面失灵 + 安全提示」，第一件事就是 `icacls <目录>` 看 `Mandatory Label`。
